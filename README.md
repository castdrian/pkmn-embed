# pkmn-embed
Pretty Discord embeds containing Pokémon metadata

## Usage
Replace `:id` with a Pokémon species name in `https://embed.pkmn.dev/:id` and paste the link into Discord.

Add `?sprite=shiny` for the shiny sprite, `?sprite=back` for the back sprite, or `?sprite=shiny%26back` for the shiny back sprite.
